How this pipeline works

A cloud agent sweeps eleven lanes twice weekly (Mon/Thu ~07:00 UTC), ranks what it finds against the £100k+ / £500-a-day floor, and writes the report to jobs/reports/ on branch job-scout-reports. It sends email applications itself, but only to addresses printed in the listing — never guessed, never enriched, capped at five a run. It has now found zero printed addresses three runs running, because search returns paraphrased summaries rather than advert contact blocks and page fetching is blocked.
