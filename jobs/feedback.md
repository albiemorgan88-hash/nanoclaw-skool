# Job Scout feedback inbox

Edit this file (GitHub mobile works fine) and the next scout run will act on it,
update the tracker, then clear the inbox section below.

Commands — one per line under INBOX, matching roles by company or role name:

- `applied: <company / role>` — mark applied (note: Gmail drafts you actually send are auto-detected, no entry needed)
- `skip: <company / role>` — drop it and don't re-show
- `more like: <company / role>` — bias future ranking toward this kind of role
- `note: <anything else the scout should know>` — e.g. "got an interview at X", "raise the salary floor to £90k"
