# CV drop point

Put the current CV PDF here (e.g. `phil-patterson-cv-v2.pdf`). 

- The **cloud scout** attaches whatever PDF it finds in this folder to email applications
  (step 8 of the routine). Until a PDF is here, email applications say "CV available on
  request and on LinkedIn" instead.
- The **local apply leg** already holds CV v2 locally and uses it for form uploads; keeping
  a copy here keeps both legs on the same version.

One file only — replace it, don't accumulate versions.
